设计原则

四条贯穿全部 14 页的硬规则,审核时可逐页对照检查。

① 玻璃只给悬浮层,内容区保持实体

L1 玻璃(blur 28px)用于侧栏/顶栏/composer/右停靠;L2 玻璃(blur 44px)只用于弹层。消息流、表格、卡片全部实体色,保证可读性与滚动性能;同屏 backdrop-filter ≤ 4 个,弹层打开时右停靠自动降为实体色。

② 语义色只有四色 + 极光签名

成功 苔绿 / 警示 琥珀 / 危险 珊瑚 / 信息 天青,全站唯一;品牌紫只做「可交互」信号。签名元素是玻璃面板上缘 1px 极光发丝线(violet→cyan),只在 composer、命令面板、激活卡出现。

③ 一个概念一个词,四处一致

任务 / 收件箱 / 连接 / 指挥台 / 多方案对比 —— 侧栏 = 页头 = 面包屑 = 快捷键提示统一;状态枚举永不直出数据库值。详见下方术语表。

④ 诚实优先:能力边界可视化

不支持的能力用琥珀虚线徽章明说(如 remote MCP「桌面端即将支持」);自动暂停、预算触顶、附件被拒全部给结构化回执,不造「说谎 UI」。

术语与信息架构对位表

路由与代码标识符不变,只改显示层;对位竞品公共词汇,降低迁移认知成本。
